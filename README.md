# Laptop specification map
A program to show a customisable map of laptops displaying their core specs

This is more of a tool I am working on for personal use than a project to showcase, but I'm uploading it here for ease of access and editing so feel free to follow along in its progress.

Note: each chunk of edits may make the code nonfunctional as I save after each session whether I have finished the part I was working on or not.

---

### About

I'm creating this tool in order to hold and save locations of laptops in a display, showing their rough specs and code to look them up further. Eventually I will add the ability to save configurations, but that's going to be a whole ordeal to learn in itself, so for now it's just the foundation of the GUI.

I know I could probably look up online for a simple enough graphic design program to do this, but I thought I'd try take it on as a challenge to test my skill and learn more. By the time this is done, the purpose for which I'm making it may be obsolete, but I'd have learned a lot so it's worth it anyway.
